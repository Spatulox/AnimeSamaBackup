⚙️ Options - Anime-sama Sync

ℹ️ Informations

Lit les informations des pages des sites anime-sama.* (progrès, épisodes, etc.) pour les stocker uniquement en local dans votre navigateur. Toutes les données collectées restent sur votre ordinateur.


Comment utiliser l'extension :

  • Activez l'extension sur Anime-sama
  • Les données se synchronisent automatiquement
  • Utilisez "Exporter" pour sauvegarder vos données dans un fichier
  • Utilisez "Importer" pour restaurer une sauvegarde depuis un fichier

Format des sauvegardes : Fichiers JSON contenant hostname + data + timestamp
